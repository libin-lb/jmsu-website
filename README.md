# 佳木斯大学官网（示例项目）

基于 **Vite + React + React Router** 开发的大学官网演示站点，包含首页、学校概况、院系设置、新闻公告（含详情页）、招生信息、联系我们等页面。

## 功能页面

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/` | 首页 | 英雄横幅、学校数据、快速入口、新闻动态、院系预览、招生宣传 |
| `/about` | 学校概况 | 学校简介、历史沿革时间轴、办学理念 |
| `/departments` | 院系设置 | 16 个学院卡片，支持按学部筛选 |
| `/news` | 新闻公告 | 校园新闻 / 通知公告 / 学术活动，支持分类筛选 |
| `/news/:id` | 新闻详情 | 单篇新闻全文展示 |
| `/admissions` | 招生信息 | 报考流程、招生专业目录、奖助学金、咨询方式 |
| `/contact` | 联系我们 | 联系方式 + 在线留言表单 |

## 本地运行

```bash
npm install     # 安装依赖
npm run dev     # 启动开发服务器（默认 http://localhost:5173）
npm run build   # 生产构建，输出到 dist/
npm run preview # 本地预览构建产物
```

## 项目结构

```
src/
├── components/        # Header、Footer、PageBanner、ScrollToTop
├── pages/             # 各路由页面
├── data/              # 站点信息、院系、新闻、招生等数据
├── index.css          # 全局样式
├── App.jsx            # 路由配置
└── main.jsx           # 应用入口
```

## 说明

- 网站内容（新闻、院系、招生等）均为**示例数据**，存放在 `src/data/` 目录下，修改对应文件即可更新页面内容。
- 学校真实信息、联系电话请以官方渠道为准。
